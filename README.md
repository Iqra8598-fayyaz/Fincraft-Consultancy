# Fincraft Consulting Website

A modern, responsive website for Fincraft Consulting, featuring tax consulting services, blog posts, and user authentication.

## Features

- Modern, responsive design
- User authentication (login/register)
- Blog section
- Contact form
- Email notifications
- Mobile-friendly interface

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Nodemailer for email functionality

## Getting Started

1. Clone the repository:
```bash
git clone [your-repository-url]
cd taxconsulting_frontend
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env.local` file in the root directory and add your email configuration:
```
GMAIL_APP_PASSWORD=your_gmail_app_password
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is deployed on Vercel. To deploy your own instance:

1. Create a GitHub repository
2. Push your code to GitHub
3. Sign up for [Vercel](https://vercel.com)
4. Import your GitHub repository
5. Deploy!
